# Mobile Application

The Scan-Go Smart Trolley uses a mobile application as the user interface for the shopping process.

The application allows the user to select products, scan product QR codes, view the shopping cart, and interact with the trolley system through Firebase.

---

## Main Features

- Start Shopping
- Product selection
- Product QR code scanning
- View Cart
- Firebase integration
- Shopping task synchronization
- Payment interface
- Trolley status communication

---
